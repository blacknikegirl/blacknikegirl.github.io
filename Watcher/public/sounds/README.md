Drop your custom direction sounds in this folder using these exact filenames:

- up.wav
- down.wav
- left.wav
- right.wav

How it works:
- The app preloads these files at camera start for immediate playback.
- If a file is missing or invalid, the app falls back to an internal tone for that direction.

Recommended format for lowest latency:
- WAV PCM, mono or stereo
- 44.1kHz or 48kHz
- Short clips (100ms to 500ms)
